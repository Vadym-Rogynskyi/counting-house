# Counting House

A personal budget tracker by Vadym Rogynskyi. Log income and expenses by category, watch spending trends, and set monthly limits with a visual burn-down.

**Live site:** https://vadym-rogynskyi.github.io/counting-house/

The whole app is one self-contained `index.html` file with no build step. Your entries are saved in your own browser (localStorage), so nothing leaves your device.
